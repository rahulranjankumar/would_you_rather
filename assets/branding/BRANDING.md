# Branding — IMPORTANT

This app is an **Accenture** internal Fun Friday activity, played by the team on the
**Currys** project. Accenture is the primary brand (employer); Currys is shown as the client.

## ⚠️ Replace the placeholder logos before real use

The two SVG files here (`accenture-logo.svg`, `currys-logo.svg`) are **plain fallback
wordmarks**, NOT the official logos. They exist only so the app never breaks.

Before using this in front of people, drop in the official, approved logo files:
1. **Accenture logo** — from the internal **Accenture Branding Portal**. Save as `accenture-logo.svg` (or `.png`).
2. **Currys logo** — an **approved** client asset. Save as `currys-logo.svg`.

Keep correct colours, don't distort, preserve clear space. Do not create AI-generated logos.

- Option colours: purple `#A100FF`, teal `#00E0C8`, magenta `#FF4FD8`, amber `#FFB020`
- Background: deep space gradient (`#0a0713` → `#161228`)
